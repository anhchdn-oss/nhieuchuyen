ra màn hình chính

Vào app như app thật, không cần mở trình duyệt mỗi lần

Bước 1: Mở app này bằng Safari (không dùng Chrome / Facebook / Messenger).
Bước 2: Bấm nút Chia sẻ ⬆️ ở thanh dưới cùng của Safari.
Bước 3: Kéo xuống, bấm “Thêm vào Màn hình chính” / Add to Home Screen.
Bước 4: Bấm Thêm / Add ở góc phải trên. Xong! Icon 🤪 sẽ nằm ngoài màn hình chính.

Mẹo: Nếu không thấy nút Chia sẻ, bấm nút aA trên thanh địa chỉ → chọn Thêm vào Màn hình chính.

Bước 1: Mở app này bằng Chrome trên điện thoại Android.
Bước 2: Bấm nút ⋮ (3 chấm) ở góc phải trên của Chrome.
Bước 3: Bấm “Thêm vào Màn hình chính” / Add to Home screen (hoặc Cài đặt ứng dụng / Install app nếu Chrome hiện).
Bước 4: Bấm Thêm / Add → Thêm tự động / Add automatically. Xong! Icon 🤪 sẽ nằm ngoài màn hình chính.

Mẹo: Một số máy Samsung dùng trình duyệt Samsung Internet thì bấm ☰ Menu → Thêm trang vào → Màn hình chính.
